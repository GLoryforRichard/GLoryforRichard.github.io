Similarweb 站点关键词 Website explorer › Keywords

把竞品的关键词表完整扒下来：每个词带来多少点击、排名难度、搜索量、CPC、零点击率、落到哪个页面。

本章你将学到
  • 打开任意网站的关键词报告，看懂每一列
  • 用机会卡片和筛选器快速找到值得做的词
  • 从"Top URL"看出竞品是用哪个页面承接哪类词的

打开方式：Keyword research → Website explorer → Keywords关键词，在弹出的搜索框里输入网站（可以是域名，也可以是具体 URL，例如 remove.bg/es）。

报告顶部

关键词表：点击、变化、难度

关键词表：搜索量、CPC、零点击

表格可以左右滚动，往右是另一组重要指标：

再往右还有 Top URL（这个词主要落到网站的哪个页面）和 SERP features（搜索结果里出现了哪些特殊展示位）。例如 quitar fondo 的 Top URL 是 remove.bg/es，remover fundo 是 remove.bg/pt-br——竞品用独立的语言页面承接各国的本地词。

怎么从词表里找机会

去掉品牌词：Branded/non-branded 选 Non-branded，排除 "remove bg" 这类带品牌名的词。

按难度排序：点 KD 列表头，从低到高看，找 KD 低于 60、点击量还不错的词。

看 Volume 和 Avg. volume 的差距：当前量远高于平均量的，是正在变热的词，越早做越有利。

看 Top URL：竞品用什么页面承接这个词？如果只是首页顺带排上去的，你做一个专门的页面就很有机会。

动手试一试
  1. 打开 remove.bg 的 Keywords 报告，筛选 Non-branded，按 KD 升序，找出 5 个 KD 低于 60 的词。
  2. 在 Include/Exclude URLs 里只看 remove.bg/es，看看西语页面一共排了多少个词。
  3. 点 Add Site for Keyword Gap 加入 photoroom.com，找出 photoroom 有排名、remove.bg 没有的词。
