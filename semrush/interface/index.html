Semrush 界面导览与通用控件

先认路：左侧的工具箱和 SEO 菜单、顶部搜索框，以及每个报告都有的数据库、设备、日期控件。

本章你将学到
  • 认识左侧的工具箱导航，知道 SEO 菜单里每一组工具解决什么问题
  • 会用顶部搜索框打开任意域名或关键词的报告
  • 掌握报告顶部的通用控件：数据库（国家）、设备、日期、子报告标签

登录后看到的是 Semrush 首页。不管查什么，操作路径都是同一个套路：

顶部搜索框输入域名或关键词 → 进入对应报告 → 用报告顶部的控件换国家、设备、日期 → 在左侧菜单里切换到相关报告

左侧导航：工具箱和 SEO 菜单

左侧最窄的一列是工具箱，鼠标移到某个图标上，会弹出这个工具箱的菜单。本教程主要用 SEO 工具箱。

菜单名称会变

Semrush 经常调整菜单。比如以前叫 Organic Research 的报告，现在叫 Organic Rankings；Keyword Manager 改名成了 Keyword Strategy Builder。找不到某个报告时，直接在顶部搜索框旁的 "Go to tool..." 里搜报告名。

顶部搜索框和报告通用控件

打开任意一个报告（下图是 remove.bg 的 Domain Overview），顶部这几排控件在大部分报告里都一样：

常用报告怎么打开

想看什么打开方式
一个网站的整体情况搜索框输入域名 → Domain Overview
一个网站排在哪些词上SEO 菜单 → Organic Rankings → Positions
一个网站哪些页面流量最大SEO 菜单 → Top Pages
几个网站的关键词差距SEO 菜单 → Keyword Gap，填入 2–5 个域名
一个词的搜索量和难度搜索框输入关键词 → Keyword Overview
围绕一个词拓词SEO 菜单 → Keyword Magic Tool
一个网站的外链SEO 菜单 → Backlinks

不要在别人能看到的地方建项目

Site Audit、Position Tracking、Backlink Audit、On Page SEO Checker 这类工具要先建 Project（项目），项目和收藏的关键词清单会保存在账号里。如果你用的是多人共用的账号，别人也能看到；而且首页、搜索框下拉里出现的"最近查询"，也可能是别人查过的网站。

动手试一试
  1. 把鼠标移到左侧的 SEO 图标上，依次找到 Domain Overview、Keyword Magic Tool、Backlinks 三个报告。
  2. 打开 remove.bg 的 Domain Overview，把数据库从 Worldwide 切到 US，记下 Organic Traffic 前后的变化。
