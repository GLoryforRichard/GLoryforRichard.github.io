Semrush 自然排名 Organic Rankings

一个网站在谷歌上排在哪些词、第几名、每个词带来多少流量，以及最近新排上和掉出的词。

本章你将学到
  • 用 Organic Rankings 查出一个网站的全部排名词
  • 看懂 Positions 表格里的每一列，会用筛选找出"快赢词"
  • 用 Position Changes 发现竞品最近新排上的词

打开方式：SEO 菜单 → Competitive Analysis → Organic Rankings自然排名（旧版叫 Organic Research），或在 Domain Overview 里点 Organic Research 区块的 View details。

Overview：排名概况

排名变化：最近新排上了哪些词

Overview 再往下，有最重要的两张卡片：

盯竞品的 New 关键词

竞品新排上的词，往往对应它刚上线的新页面或新功能。每个月看一次竞品的 Position Changes › New，按搜索量排序，是发现新需求最省力的办法——和 Similarweb 的 New Clicks 思路一样。

Positions：完整排名表

切到 Positions排名 标签，就是这个网站全部排名词的表格。表格上面先是一排筛选：

用筛选找"快赢词"

想找什么筛选条件为什么
快赢词Positions 4–20，Volume > 500已经在第一、二页，稍微优化就可能进前三
竞品的商业词Intent = Commercial / Transactional这些词离付费最近
非品牌词Advanced filters → Keyword 不包含 remove bg、removebg排除品牌词，才能看出 SEO 真实能力
某个功能的词Advanced filters → URL 包含 /f/只看某一类页面带来的词
新兴需求Position Changes › New，按 Volume 排序竞品最近排上的词
动手试一试
  1. 在 remove.bg 的 Positions 里筛选 Positions 4–20、Volume 大于 1,000，看看还有哪些词有机会冲进前三。
  2. 用 Advanced filters 排除品牌词，找出 remove.bg 流量最大的 5 个非品牌词。
  3. 打开 photoroom.com 的 Position Changes，看看它最近新排上了哪些词。
