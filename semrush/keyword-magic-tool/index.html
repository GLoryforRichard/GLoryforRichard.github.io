Semrush 拓词 Keyword Magic Tool

输入一个种子词，拓出几万个相关词，再用匹配方式、分组和筛选，把可以做的长尾词挑出来。

本章你将学到
  • 用 Keyword Magic Tool 从一个种子词拓出全部相关词
  • 分清 Broad、Phrase、Exact、Related 四种匹配方式
  • 用左侧分组和 KD、Include、Exclude 筛选，把几万个词缩小到可以做的几十个

打开方式：SEO 菜单 → Keyword Research → Keyword Magic Tool拓词魔法工具，输入种子词；或在 Keyword Overview 的 Keyword Variations 里点 View all。

界面一览

匹配方式返回什么remove background 的例子
Broad Match包含种子词里的每个单词，顺序不限，含单复数等变形background remover、remove bg from image
Phrase Match包含完整短语，顺序不变how to remove background in canva
Exact Match包含完整短语，顺序和形式都不变remove background free
Related语义相关、但不一定包含这些单词的词transparent background、cutout image

一个够用的拓词流程

  1. 种子词用最短的核心词（remove background、background remover），匹配方式先选 All Keywords
  2. 先扫左侧 Groups，记下和你产品相关的组（video、gif、canva、photoshop……）
  3. KD % 选 Possible 及以下，Volume 设 500 以上
  4. 用 Exclude keywords 排除无关词，用 Include keywords 聚焦某个功能
  5. 把剩下的词逐个丢进 Keyword Overview 看 SERP，确认前十名里有弱页面

少用 Export 和翻页

Keyword Magic Tool 一页 100 个词，每翻一页、每换一次筛选都会消耗报告次数。先用筛选把范围缩小，再翻页；多人共用的账号尽量不要导出整张表。

动手试一试
  1. 用 background remover 当种子词，选 Phrase Match，对比结果数量和 All Keywords 的差别。
  2. 点左侧的 video 组，筛选 KD 低于 50，记录 5 个和视频去背景有关的词。
  3. 切到 Questions，找出搜索量最高的 3 个问题词。
